<center><h1> CANN代码托管平台迁移公告 </h1> </center>

**尊敬的CANN社区开发者：**

CANN社区致力于构建开放、共享的技术生态，并为开发者和用户提供更好的产品和服务。为了进一步提升开发者体验和数据安全性，经CANN社区技术指导委员会评估和决议，我们决定将CANN社区的代码托管平台从Gitee平台（ https://gitee.com/ascend 以及 https://gitee.com/cann ） 迁移至GitCode平台（ https://gitcode.com/cann ）。此次迁移主要基于技术优化需求，旨在为开发者提供更稳定、高效的代码托管服务，同时更好地整合现代化开发工具。

**自本公告发布之日起，我们将正式启动CANN社区的数据迁移工作，包括社区贡献数据和个人信息。**

    

**对于社区贡献数据（含issue、PR等），我们将根据与您签署的贡献者许可协议（CLA协议）进行迁移。** 本次迁移开始后，**托管在GitCode平台上的CANN社区仓库开始接受代码提交与问题反馈，托管在原Gitee平台的CANN社区仓库将设置成只读，** 您将无法在原Gitee平台贡献issue和PR等数据。

**对于您在贡献代码过程中涉及的个人信息（Gitee ID、昵称、授权公开邮箱）将通过您的单独同意进行迁移：**
* **未注册GitCode账号的用户，推荐您使用Gitee账号授权登录并注册GitCode账号，通过提交issue的方式完成《个人信息迁移同意书》的签署，方便CANN社区对您的历史贡献进行维护和管理。**
* **已注册GitCode账号的用户，您的GitCode账号需要关联Gitee账号(https://gitcode.com/setting/account)， 再通过提交Issue的方式完成《个人信息迁移同意书》的签署，方便CANN社区对您的历史贡献进行维护和管理。**

**如果您有任何疑问可以咨询GitCode平台客服。**
* **已签署前述《个人信息迁移同意书》的用户，您在Gitee平台提交的issue、PR等内容以及个人信息将迁移至 GitCode 平台，用户能在新平台上查看和管理这部分数据。**
* **未签署前述《个人信息迁移同意书》的用户，您在Gitee平台的个人信息将不予迁移，只迁移在Gitee平台提交的issue、PR等内容本身，在GitCode平台上不展示issue、PR关联的用户信息，但用户仍可通过 Gitee平台访问历史数据。**

_[点击签《个人信息迁移同意书》>>>](https://gitcode.com/cann/cann-agreements/issues/create?type=template&title=%E4%B8%AA%E4%BA%BA%E4%BF%A1%E6%81%AF%E8%BF%81%E7%A7%BB%E5%90%8C%E6%84%8F%E4%B9%A6&template=.gitcode%252FISSUE_TEMPLATE%252Fauthrization.yml)_

我们将在整个迁移过程中确保数据的完整性与安全性，同时为您提供详尽的指导和支持，帮助您快速适应新平台的操作环境。

如果您有任何疑问或投诉，您可以发送邮件至 kefu@gitcode.com 邮箱或电话：400-6868-951 联系我们。一般情况下，我们将在15个工作日内回复。

**常见问题解答（FAQ）**

Q1：迁移是否会影响现有分支与标签？

A：所有历史记录将完整保留，仅仓库地址变更。

Q2：未合并的PR如何处理？

A：请在新平台重新提交，我们将优先审核迁移期内的贡献。
